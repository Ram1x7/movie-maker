# Heartopia 切り抜き・動画編集ツール

Heartopiaの切り抜き/動画編集向けに作った4つの単一HTMLツールです。ビルド不要、サーバー不要。GitHub Pagesなどの静的ホスティングにそのまま置くだけで動きます。

- **[buzz-structure-ai.html](./buzz-structure-ai.html)** — バズる構成案の提案(企画モード)+ 既存のYouTube/TikTok動画のリサーチモード(oEmbed取得・Whisper文字起こし・バズ要因分析)
- **[clip-finder-ai.html](./clip-finder-ai.html)** — 切り抜き箇所の提案(字幕解析・動画フレーム解析・Whisper自動文字起こし)
- **[post-assist-ai.html](./post-assist-ai.html)** — テロップ/効果音/BGMの選定提案
- **[edit-timeline-ai.html](./edit-timeline-ai.html)** — 「バズる構成AI」(企画モード)と「切り抜きファインダーAI」の結果を統合し、CapCut等での手作業編集にそのまま使える編集タイムラインを生成

4ツールとも同じデザインで、上部のナビゲーションから相互に移動できます。

## 使い方

### 1. デプロイする

このリポジトリをそのままGitHub Pagesで公開するか、任意の静的ホスティング(Netlify, Cloudflare Pagesなど)にアップロードしてください。ビルドステップは不要です。ローカルで確認する場合は、リポジトリ直下で簡易サーバーを立てて開いてください(`file://`で直接開くとブラウザによってはモジュール読み込みが失敗します)。

```bash
python3 -m http.server 8000
# → http://localhost:8000/buzz-structure-ai.html など
```

### 2. Anthropic APIキーを設定する

各ツールはブラウザから直接 `api.anthropic.com` を呼び出します。バックエンドサーバーはありません。初回利用時、画面右上の🔑アイコンから[Anthropic Console](https://console.anthropic.com/settings/keys)で発行したAPIキー(`sk-ant-...`)を入力してください。

- キーはこの端末のブラウザの`localStorage`にのみ保存され、`api.anthropic.com`以外には送信されません。
- 同一オリジンで動く他のスクリプト(悪意ある拡張機能など)からは読み取られる可能性があるため、共有・公共のPCでは使用後に🔑アイコンから「削除」してください。
- このツール専用に利用上限額を絞ったAPIキーを発行することを推奨します。
- キー未設定のまま生成を実行すると、エラーメッセージとともに設定モーダルが自動的に開きます。

### 3. 各ツールを使う

すべて日本語UIです。フォームに入力して生成ボタンを押すだけで、Claude(`claude-sonnet-5`)がJSON形式で結果を返し、画面に整形して表示します。

## リサーチモード(複数動画の共通パターン抽出)について

`buzz-structure-ai.html`のリサーチモードでは、参考にしたい動画のURLを3〜5本まとめて入力できます(「+ 動画を追加」で最大5本、最低1本)。各動画のURL・oEmbed情報・文字起こし(手入力 or Whisperで自動)・統計情報をそれぞれ入力し、「まとめて分析する」を押すと以下の流れで処理します。

1. 各動画を個別に分析(バズった要因・タイトルの型・応用ポイント)。進捗は「N/M本目を分析中...」と画面に表示されます。
2. 全動画の分析がそろったら、それらに共通する構成の型・パターンを抽出する2回目のAI呼び出しを行います。
3. 共通パターンのサマリーに加えて、それを踏まえた新しい構成案(タイトル案・タイムライン・投稿のコツ)を出力します。出力フォーマットは企画モードの結果と同じ形式なので、右上の🕘履歴や「この結果をコピー(編集タイムライン統合AI用)」ボタンがそのまま使えます。

## 文字起こし(Whisper)について

`buzz-structure-ai.html`(リサーチモード)と`clip-finder-ai.html`は、[@xenova/transformers](https://github.com/xenova/transformers.js)を使ってブラウザ内でWhisperによる文字起こしができます。

- 処理はすべて端末内で完結し、動画ファイルはどこにも送信されません。
- 初回はモデル(tiny/base/small)のダウンロードに数十秒〜数分かかりますが、以降はブラウザにキャッシュされます。
- ファイルサイズが500MB超、または動画の長さが20分超の場合、処理が重くなる可能性がある旨の警告が表示されます。

## 動画情報の自動取得(oEmbed)について

`buzz-structure-ai.html`のリサーチモードでは、TikTok/YouTubeのoEmbedエンドポイントからタイトル・投稿者・サムネイルを自動取得します。TikTok側のCORS制限などで自動取得に失敗した場合は、「手動で入力する」からタイトル・投稿者を直接入力して進められます。

## 編集タイムライン統合(edit-timeline-ai.html)について

「バズる構成AI」の構成案(フック・展開などの役割)と「切り抜きファインダーAI」のスコア付き候補(実際の元動画のタイムコード)を組み合わせて、CapCut Pro等で手作業編集する際にそのまま見ながら作業できるタイムラインを作成します。

使い方:
1. `buzz-structure-ai.html`の企画モードで構成案を生成し、結果画面の「この結果をコピー」ボタンでJSONをコピー(または後述の履歴プルダウンから選択)
2. `clip-finder-ai.html`で切り抜き候補を生成し、同様に「この結果をコピー」でJSONをコピー(または履歴プルダウンから選択)
3. `edit-timeline-ai.html`の該当欄にそれぞれ貼り付けて生成

※ CapCutの独自プロジェクトファイル(`.draft_content.json`)を直接生成してインポートする方式は、非公開・未文書化のフォーマットで壊れるリスクが高いため採用していません。あくまで人間が画面を見ながら手作業編集するための一覧表です。

生成は2回のAI呼び出しに分かれています(タイムラインの生成 → その内容をもとにしたテンポ分析/評価/投稿文言の生成)。1回の巨大な出力にまとめると`max_tokens`の上限で途中で切れるリスクが上がるため、内容ごとに分割しています。2回目が失敗した場合でも、1回目で生成済みのタイムライン自体は表示されます。

各シーンには、既存のロール/タイムコード/理由/テロップ/SE案に加えて、以下の情報が付きます(既存フィールドの削除・変更はなく、追加のみです):

- **重要度** (5=絶対使う 〜 1=予備)・**感情**タグ
- **編集演出**: ズーム(なし/110%/120%/顔アップ)・カメラ(通常/揺れ/パンチイン)・リアクションの大きさ
- **テロップ詳細**: 文言・表示位置・スタイル・色・アニメーション
- **音声情報**: ゲーム音の扱い・BGM音量・リアクション音声・追加SE

結果画面の追加機能:
- **📋 編集指示書**: 上記の情報を「00:00〜00:03 ・フック ・ゲーム音: keep ・BGMなし ...」のような編集ソフトでそのまま見られる箇条書き形式にまとめたビュー(ボタンで表示/非表示切り替え)。
- **⏱ 尺調整(30/45/60秒版)**: 重要度をもとに、尺の短いシーンから優先的に残しつつ低重要度のシーンを自動で間引いた候補を表示します。追加のAI呼び出しはせず、既に生成済みのタイムラインをその場で計算するだけです。
- **テンポ分析**: 動画全体をHook/Calm/Reaction/Peak/Endingの5フェーズに区分し、テンポが落ちている箇所があれば具体的な改善案とともに表示します。
- **Editor Tips / 編集時間短縮ポイント**: 編集者向けの具体的なアドバイス。
- **AI評価**: フック・テンポ・オチ・リアクション・視聴維持率・タイトル・コメント誘導・シリーズ性の8項目(各10点満点)と、その合計を100点満点に換算した総合スコア。
- **投稿支援**: YouTube Shorts用タイトル・TikTok用タイトル・概要欄・検索向けハッシュタグ・コメント固定文案(各項目にコピー用ボタン付き)。

以前生成・保存された(このアップデート前の)結果を🕘履歴から読み込んだ場合も問題なく表示されます。新しいフィールドが無い分のセクションは自動的に省略されるだけで、エラーにはなりません。

## 結果の履歴について

4ツールすべてに、生成した結果を自動保存する履歴機能があります。

- 生成に成功するたびに、その結果がこのブラウザのlocalStorageに自動保存されます(ツールごとに最新20件まで)。
- 画面右上の🕘アイコンから、過去の結果一覧を開けます。各結果は「読み込む」(画面に再表示)・「JSONをコピー」・「削除」ができます。
- 保存先はこの端末のブラウザのみで、他の人やサーバーには送信されません。別の端末/ブラウザからは見えません。
- `edit-timeline-ai.html`では、貼り付け欄の上のプルダウンから`buzz-structure-ai.html`・`clip-finder-ai.html`で生成した過去の結果を直接選んで読み込めます(同一オリジンのlocalStorageを直接参照するため、手動コピー&ペーストで内容が途中で切れる心配がありません)。

## 構成案のお気に入り保存(buzz-structure-ai.html)について

`buzz-structure-ai.html`では、結果画面の「⭐ お気に入り保存」ボタンで構成案を永続的に保存できます。

- 自動保存される履歴(直近20件でローテーションされ、古いものは自動的に消えます)とは別の保存領域です。⭐で保存した構成案は、件数の上限なく、削除するまでこの端末にずっと残ります。
- 保存時に任意でタイトル/メモを付けられます(空欄のままでも保存できます)。
- 画面右上の⭐アイコンから保存済み一覧を開き、各項目を「読み込む」・「JSONをコピー」・「保存解除」できます。
- 履歴と同じくこの端末のブラウザのみに保存され、他の人やサーバーには送信されません。

## フリーBGMの提案(post-assist-ai.html)について

`post-assist-ai.html`のBGM提案には、フリー(無料/ロイヤリティフリー)BGM素材サイトで探す際に使える検索キーワードと、素材サイトへのリンクが含まれます。

- AIが実在しない曲名やアーティスト名を創作することを避けるため、AIが出すのは「ジャンル・雰囲気・テンポ」を踏まえた検索キーワード(例: 「高揚感 EDM」「コミカル 軽快」)のみです。
- 素材サイト自体(DOVA-SYNDROME、甘茶の音楽工房、Otologic、魔王魂、HURT RECORD、YouTubeオーディオライブラリ)はAI生成ではなく固定のリンク集で、そのキーワードで検索して実際の曲を探していただく形です。
- 「フリー」でも曲ごとにクレジット表記の要否・商用利用可否などのライセンス条件が異なるため、使用前に各サイト・各曲の利用規約を必ずご確認ください(結果画面にも注意書きが表示されます)。

## リポジトリ構成

```
buzz-structure-ai.html   バズる構成AI(企画モード / リサーチモード)
clip-finder-ai.html      切り抜きファインダーAI
post-assist-ai.html      テロップ/SE/BGM選定AI
edit-timeline-ai.html    編集タイムライン統合AI
shared/
  api-client.js          Anthropic APIキーの管理・設定モーダル・fetchラッパー
  whisper.js             ブラウザ内Whisper文字起こしの共通処理
  history.js             結果履歴の保存(localStorage・直近20件ローテーション)・履歴モーダルUI
  favorites.js           構成案のお気に入り永続保存(localStorage・件数上限なし)・保存済み一覧モーダルUI
  nav.js                 4ツール共通のナビゲーションバー
  theme.css               共通デザイントークン・ベーススタイル
```

## セキュリティに関する注意

- APIキーはブラウザの`localStorage`に保存されます。パスワードと同様に扱ってください。
- リポジトリやビルド成果物にAPIキーを含めないでください(このツールはその場で入力する方式のため、通常は問題になりません)。
- 本番でより高いセキュリティが必要な場合(APIキーをサーバー側で秘匿したい場合)は、Cloudflare Workers等の軽量プロキシを別途用意する構成に変更することも可能です。
